## 验收口径

1. 数据：训练、验证、评测的任务和同图不交叉；图片、动作、来源与质量问题均可追溯。最终可用数量以实际审计为准。
2. 训练：至少完成一次可复现的小规模训练、adapter 保存与重载推理；记录显存和失败，不把“脚本能启动”当作训练完成。
3. 对比：保留逐例输入输出；离线动作合法率、动作正确性与真实 GUI 完成率分别统计。只有接入真实模型、实际执行并通过双重确认的用例，才能计入真实任务完成率。
4. 恢复：重试有上限；未派发输入的观察/定位失败可以重试，部分输入和提交状态不确定时停止并留证，不能自动重复发送。
5. 报告：按测试类型、功能模块、数量列出结果，附真实截图、失败分类与修复前后记录；未完成的 NIM、缩放或应用适配继续标待测。
