# 仓库内容说明

本仓库以私有方式保存实习项目的开发成果，包括：

- 三个核心 Python 模块、命令行入口、独立测试窗口及 JSON 任务计划。
- 单元测试、检查与打包工具、环境安装文件和依赖版本快照。
- 各阶段使用说明、验证记录、架构说明、交付清单及 README。
- Word 实验报告、个人计划、源码交付包。
- 可控 OCR 图片与独立验证窗口产生的截图、标注、JSON、文本和动作日志，包括保留的早期失败记录。

以各阶段验证记录和汇总中的最终通过结果为验收依据，不能将目录内每一次历史运行都视为通过。

虚拟环境、可自动下载的模型权重、Python 缓存、临时排版检查文件、Office 锁文件和本地凭据不提交。`output/wednesday/` 与 `output/thursday/` 中的普通桌面截图保留在本机，避免把项目之外的屏幕内容混入实验资料。

当前源码交付压缩包是周六整理时的快照，不包含后来生成的 Word 实验报告和 GitHub 仓库说明。仓库中的当前文件为完整开发与文档版本，历史压缩包继续保留供追溯。

新电脑需按 README 安装 Python 运行依赖和 CUDA 版 PyTorch；EasyOCR 会在首次识别时下载模型。归档内容不包含原始项目大纲 PDF，该文件仍保留在本机下载目录。

第二周增加 `gui_data/` 数据管线与 `gui_agent/` 模型接口，以及周一、周二配套说明、测试与摘要。Git 提交按第一周修订、第二周周一数据处理、第二周周二 Agent 接口分批保存；第一周原有初始提交继续保留。

第二周原始数据与派生图片位于本机 `data/week2/`，不纳入 Git。模型接口运行时的截图、任务、历史和响应同样留在本机；`output/week2-tuesday/` 只允许不含上述内容的验证索引入库。文档中的这些本地图片和运行详情链接，需在具备相应本地数据时查看。NVIDIA API 密钥由环境变量提供，不上传仓库。真实模型推理因服务端排队导致首次超时，继续标注待测。

2026 年 11 月 6 日补充同步第二周周三至周五和第三周周一、周二成果，第二周与第三周分别提交。包括规划与执行集成、五类任务测试、输入故障诊断、两周 Word 汇报及截图记录包，以及视觉数据审计、本地 LoRA 训练与恢复代码、配置、测试和配套文档。
